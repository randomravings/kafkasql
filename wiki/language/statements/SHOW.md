# SHOW

Navigation: [Up](Home.md) | [Home](../../Home.md)

Lists metadata objects.

## Syntax

```kafkasql
SHOW CONTEXTS;
SHOW TYPES;
SHOW STREAMS;
SHOW CURSORS;
SHOW USERS;
```

## Example

```kafkasql
SHOW CURSORS;
```

## Notes

- SHOW is useful for discovery and debugging.
- Available SHOW targets may expand over time.
